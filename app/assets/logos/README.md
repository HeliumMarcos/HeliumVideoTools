# Identidade visual — Helium Vídeo Tools

Nome oficial: **Helium Vídeo Tools**. A identidade mantém o símbolo compacto para funcionar bem na barra de tarefas e usa o nome completo na interface.

1. **Helium Atom (recomendado e adotado):** duas órbitas e dois elétrons remetem diretamente ao átomo de hélio; o núcleo vira um botão de reprodução. O gradiente Fluent azul-violeta mantém personalidade e o desenho continua reconhecível em 16 px.
2. **Prisma:** um quadro de filme transforma o play central; é mais técnico e funciona bem para uma suíte de ferramentas.
3. **Órbita:** setas circulares ao redor do play representam conversão contínua; é mais energético e adequado a uma marca de consumo.

`logo-monochrome.svg` é a versão de uma cor para barra de tarefas, documentos e superfícies sem gradiente. `logo.ico` contém 16, 20, 24, 32, 40, 48, 64, 128 e 256 px.
